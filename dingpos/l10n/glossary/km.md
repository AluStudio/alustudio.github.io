# Site glossary — ខ្មែរ (km)

Copied from `_template.md`. The km translator fills it before translating any packet, and the reviewer holds every km value to it.

This file is for words only the website uses. The app's own glossary (`l10n/glossary/km.md` in the DingPOS app repo, linked from every packet) already fixes the domain terms (Pre-order, Void, Settlement…) and the app's UI vocabulary, and every packet carries the app's exact translation of strings the site shares with the app (`appMatch`, `appTerms`). Never redefine a term those already settle; add a row here only for a word the app never shows.

Fill "Term in language" with the one word or phrase every page will use, as a shop owner in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| Support (the help pages) | ជំនួយ | Nav/page label. Avoid ការគាំទ្រ (means "backing/endorsing") |
| FAQ / frequently asked questions | សំណួរដែលសួរញឹកញាប់ | Short label may be "សំណួរញឹកញាប់" |
| Pricing (the page) | តម្លៃ | Page/nav label; "គម្រោងតម្លៃ" only when a longer phrase is needed |
| Plan (Lite / Standard / Pro; the names stay in English) | គម្រោង | from app glossary (Plan); names stay Lite / Standard / Pro |
| Free trial | សាកល្បងដោយឥតគិតថ្លៃ | Noun use: "ការសាកល្បងឥតគិតថ្លៃ" |
| Billed monthly / billed annually | ចេញវិក្កយបត្ររាល់ខែ / ចេញវិក្កយបត្ររាល់ឆ្នាំ | Short toggle labels: "ប្រចាំខែ" / "ប្រចាំឆ្នាំ" |
| Terms of Use | លក្ខខណ្ឌប្រើប្រាស់ | Privacy policy = "គោលការណ៍ឯកជនភាព" |

| Stall / pop-up / night market | តូបលក់ដូរ / តូបបណ្តោះអាសន្ន / ផ្សារយប់ | Keep "ផ្សារយប់" for night market; avoid ហាងធំ |
