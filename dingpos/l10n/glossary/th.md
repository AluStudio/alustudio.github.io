Copied from `_template.md`. The th translator fills it before translating any packet, and the reviewer holds every th value to it.

This file is for words only the website uses. Never redefine a term those already settle; add a row here only for a word the app never shows.

Fill "Term in language" with the one word or phrase every page will use, as a shop owner in that market searches for it. Add a row for any other site-only word that repeats across pages.
