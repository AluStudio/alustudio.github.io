# Site glossary — Bahasa Indonesia (id)

Copied from `_template.md`. The id translator fills it before translating any packet, and the reviewer holds every id value to it.

This file is for words only the website uses. The app's own glossary (`l10n/glossary/id.md` in the DingPOS app repo, linked from every packet) already fixes the domain terms (Pre-order, Void, Settlement…) and the app's UI vocabulary, and every packet carries the app's exact translation of strings the site shares with the app (`appMatch`, `appTerms`). Never redefine a term those already settle; add a row here only for a word the app never shows.

Fill "Term in language" with the one word or phrase every page will use, as a shop owner in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| Support (the help pages) | Bantuan | Nav/page title. "Dukungan" only for "contact support" (hubungi dukungan/tim kami) |
| FAQ / frequently asked questions | FAQ | Heading may expand to "Pertanyaan yang Sering Diajukan"; avoid "Tanya Jawab" |
| Pricing (the page) | Harga | Avoid "Tarif", "Biaya" |
| Plan (Lite / Standard / Pro; the names stay in English) | Paket | From app glossary (Plan = Paket). Note: "Paket harga" is the app's Bundle — don't use it for plans |
| Free trial | Uji coba gratis | Avoid "Percobaan gratis", "Trial" |
| Billed monthly / billed annually | Ditagih per bulan / Ditagih per tahun | Avoid "Dibayar bulanan" |
| Terms of Use | Ketentuan Penggunaan | Avoid "Syarat dan Ketentuan" for this title |
| Coming Soon (planned features) | Segera hadir | Avoid "Akan datang" |
| Setup guide (promotion setup guides) | Panduan pengaturan | Promotions are "Promo" (app glossary) |
| Shop owner | Pemilik toko | Owner role in the app = Pemilik; "Pemilik toko" for the business reader. Avoid "Pengusaha", "Merchant" |
| Stall / pop-up / night market | Lapak / toko pop-up / pasar malam | "Lapak" for a stall; also "warung" only if en says so explicitly |
| Offline-first | Berfungsi offline | Describe as "bisa dipakai tanpa internet"; avoid "Offline-first" literal |
| Point of sale (POS) app | Aplikasi kasir (POS) | Search term in Indonesia is "aplikasi kasir"; avoid "Titik penjualan" |
