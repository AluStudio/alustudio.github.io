# Site glossary — Français (fr)

Copied from `_template.md`. The fr translator fills it before translating any packet, and the reviewer holds every fr value to it.

This file is for words only the website uses. The app's own glossary (`l10n/glossary/fr.md` in the DingPOS app repo, linked from every packet) already fixes the domain terms (Pre-order, Void, Settlement…) and the app's UI vocabulary, and every packet carries the app's exact translation of strings the site shares with the app (`appMatch`, `appTerms`). Never redefine a term those already settle; add a row here only for a word the app never shows.

Fill "Term in language" with the one word or phrase every page will use, as a shop owner in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| Support (the help pages) | Assistance | Pas « Support » seul (ambigu en français). Registre : vouvoiement partout. |
| FAQ / frequently asked questions | FAQ | Développé : « Questions fréquentes ». |
| Pricing (the page) | Tarifs | Pas « Prix » ni « Tarification » pour le titre de la page. |
