# Site glossary template

`npm run l10n -- babbby new <code>` copies this file to `babbby/l10n/glossary/<code>.md`. The translator fills it before translating any packet, and the reviewer holds every value to it.

The Babbby app has its own glossary (`l10n/glossary/<code>.md` in the babbby-ios repo, `packet.glossary.app`): activity, the eight activity categories, Today's plan, Library, Stats, free trial, Lifetime and every other app term come from there, never from this file. This file holds only the words the website repeats that the app glossary does not define, so every page says them the same way. Never contradict the app glossary.

Fill "Term in language" with the one word or phrase every page will use, as a parent in that market searches for it. Add a row for any other site-only word that repeats across pages.
