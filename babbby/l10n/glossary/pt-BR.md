# Site glossary — Português (Brasil) (pt-BR)

Copied from `_template.md`. The pt-BR translator fills it before translating any packet, and the reviewer holds every pt-BR value to it.

The Babbby app has its own glossary (`l10n/glossary/pt-BR.md` in the babbby-ios repo, `packet.glossary.app`): activity, the eight activity categories, Today's plan, Library, Stats, free trial, Lifetime and every other app term come from there, never from this file. This file holds only the words the website repeats that the app glossary does not define, so every page says them the same way. Never contradict the app glossary.

Fill "Term in language" with the one word or phrase every page will use, as a parent in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| Baby activity app (the product category, as parents search for it) | app de atividades para bebês | «app» é a palavra que os pais brasileiros usam e buscam; «aplicativo» só em textos jurídicos e formais. Para crianças maiores, «atividades para crianças» no corpo do texto. |
