# Site glossary — Русский (ru)

Copied from `_template.md`. The ru translator fills it before translating any packet, and the reviewer holds every ru value to it.

The Sotto app has no glossary file. Its own wording reaches every packet as the app's exact translation of strings the site shares with the app (`appMatch`); the app's `ru.lproj/Localizable.strings` in the sotto repo (`sotto-ios/Targets/Sotto/Resources/`) is the reference for any other screen or field name. Never contradict the app's wording; add a row here for a word the pages repeat, so every page and guide says it the same way.

Fill "Term in language" with the one word or phrase every page will use, as a reader in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| People notes app (the product category) | приложение для заметок о близких | Store wording (listings): «Заметки о близких и подарках». Search terms «заметки о людях» / «записная книжка о людях» have no store demand: use «заметки о близких» in running text, «заметки о людях» at most once where the sentence is about the category, never stuff. Always «приложение», never «программа»/«софт». Not «записная книжка»/«контакты» (reader expects a phone-book tool). Not «дневник отношений» (the old subtitle) |
| Person page (a page for every person) | отдельная страница для каждого человека | The app calls people «человек / люди» (tab.people «Люди», editPerson.newTitle «Новый человек»); no screen is called «страница». Say «страница» only in the marketing sense; on its own: «страница человека». Not «профиль»/«карточка» (social network / CRM sound), not «досье» |
| Note (a dated note about a person) | заметка / заметки | from app strings: personDetail.noteSection «Заметка», personDetail.sectionNotes «Заметки», addNote.title «Добавить заметку». Feminine: заметка. Not «запись», «примечание», «памятка» |
| Field (size and measurement fields) | поле / поля | from app strings: editPerson.addField «Добавить поле», editPerson.fieldsSection «Поля». Custom field = «своё поле» (customField.title «Своё поле»). Size and measurement fields = «поля для размеров и мерок»; the app group is «Размеры» (personDetail.groupSizes), body group «Тело». Not «параметр»/«графа» |
| Ring size / shoe size | размер кольца / размер обуви | from app strings: settings.unitRingSize «Размер кольца», settings.unitShoeSize «Размер обуви» (field.shoeSize «Обувь»). Ring size chart = «таблица размеров колец». Systems stay US / EU / UK / JP (unit.ring*). Ring finger: «безымянный палец» in prose (the app abbreviates «Безым.» only in tight labels — do not copy the abbreviations into prose). Height = «рост» (field.height «Рост»); clothing = «размер одежды» to keep it apart from ring/shoe size. Not «размер перстня» |
| Gift idea / gift log | идея подарка / журнал подарков | Gift idea: from app strings field.giftIdeas «Идеи подарков». Gift log (a record of what you gave, when, for which occasion) = «журнал подарков» (verb «вести журнал подарков»; plain description «записывать, что и кому подарили»). Keep it apart from «вишлист» (the app's wish-list field, field.wishlistUrl «Вишлист») which is what someone wants. Not «список подарков» (reads as a wish list), not «учёт подарков» (too bookkeeping) |
| Conversation question (the question catalog) | вопрос для разговора / каталог вопросов | Button/screen wording from app strings: promptCatalog.title «Выбери вопрос», promptCatalog.searchPlaceholder «Найти вопрос» — when a page quotes the button, write it exactly so (the app uses ты there; the site's own sentences stay вы). Site noun for the catalog: «каталог вопросов»; one item: «вопрос для разговора». Not «промпт», not «стартер» |
| Guides (the article pages) | Руководства | Nav/section label; back link «Все руководства»; a single article is «руководство» (the how-to sense, not a manual). Not «гайды» (slang), not «инструкции», not «Guides» |
| FAQ / frequently asked questions | Частые вопросы | Nav label and page title «Частые вопросы»; in sentences «часто задаваемые вопросы» is fine. Do not leave «FAQ» in running text; the meta title may keep «FAQ» once if the length needs it, since Russian users search it |
| Privacy Policy | Политика конфиденциальности | from app strings: settings.privacyPolicy. Not «Политика приватности», not «Политика обработки персональных данных» |
| Terms of Use | Условия использования | from app strings: settings.termsOfUse. Not «Пользовательское соглашение» |
| One-time purchase, no subscription | единоразовая покупка, без подписки | from app strings: paywall.oneTimePurchase «Единоразовая покупка · Навсегда», paywall.subtitle «Одна покупка. Без подписки.». Never «абонемент»/«платная подписка». The paid state is «Lifetime» / «навсегда» (settings.proBadge «LIFETIME», paywall.unlockButton «Открыть навсегда»); free tier: «бесплатно», «можно начать бесплатно» |
| Back up / restore (to your own cloud) | резервная копия / восстановить | from app strings: backup.title «Резервная копия», backup.backupTo «Копия в %@», backup.restoreAction «Восстановить». Noun «резервная копия» (short «копия»); verb «создать резервную копию». Own cloud = «ваше собственное облако» (iCloud, Google Drive, Dropbox). Not «бэкап» (slang), not «архив» |
| On your phone (data stays on the device) | на вашем телефоне | Warm site wording for everything stays local (Android and iPhone alike). In legal text and where the app says it, use «на устройстве» / «локально» (appLock.footerTag «ПРИВАТНО · ТОЛЬКО НА УСТРОЙСТВЕ»). Never «в телефоне»; for the iPhone-only sentence name «iPhone» |
| Personal CRM (as the FAQ describes Sotto) | личный CRM | Store keyword (aso-keywords.md ru: «личный crm»). Use only in the sentence that says Sotto is like a personal CRM for people you love; «CRM» uppercase, masculine («личный CRM»), no expansion. The category has no proven search demand in ru: never in titles or summaries |
| Reminder (birthday / anniversary notification) | напоминание / напоминания | from app strings: notification.title «Напоминания». Birthday = «день рождения» in full on the site (field.birthday «Рожд.» is a tight-label abbreviation; never «ДР» or «Рожд.»); anniversary = «годовщина» (field.anniversary); date field = «поле с датой» (notification.noDateFields). Not «уведомление» for the feature (only for the system permission) |
| App Lock | блокировка приложения | from app strings: settings.appLock «Блокировка приложения»; lowercase in running text, capitalize only as a label. Face ID / Touch ID / iCloud stay untranslated; passcode = «код-пароль» in the app (settings.appLockDescription); on the site «код-пароль» for iPhone, «PIN-код» for Android. Not «защита паролем» |
| Color themes | темы | from app strings: paywall.themes «Все 7 тем», themePicker.title «Выберите тему». Say «цветовые темы» only on first mention. Not «скины», «оформления». (en says 8 themes; the app string says 7 — the count is en's issue, not the glossary's.) |
| No account / no sign-up | без аккаунта | from app strings: paywall.noAccount «Без аккаунта». «Без регистрации» is fine as a variation when sign-up/login is meant. Not «без учётной записи» |
| Free (free version / free limit) | бесплатная версия | from app strings: paywall.limitReachedTitle, paywall.personLimitMessage («Бесплатная версия поддерживает…»). Upgrade/Pro: «Pro», «Lifetime». Not «free» in Latin letters |
| Address form (register) | вы | Warm, one person. Lowercase вы/вам/ваш in running text (the app does the same; no capitalised Вы). Verbs in the polite plural imperative («запишите», «добавьте»). The app's catalogue headers use ты in a few spots (promptCatalog.safetyHeader.*) — do not copy that into site prose. Gender-neutral wording where possible (человек, близкие) |
| People you care about (recurring phrase) | близкие / люди, которые вам дороги | Recurring «the people you care about / love»: «близкие» (store wording) as the short form, «люди, которые вам дороги» as the full one; vary with «те, кто вам важен» (paywall.subtitle «Помните всех, кто важен»). A single one is «человек» (the app never says «контакт» for a person); «контакт» only for phone/email info (personDetail.groupContact «Контакт»). Not «любимые» unless romantic, not «родные» (means relatives) |
