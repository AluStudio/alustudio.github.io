# Site glossary — Français (fr)

Copied from `_template.md`. The fr translator fills it before translating any packet, and the reviewer holds every fr value to it.

The Sotto app has no glossary file. Its own wording reaches every packet as the app's exact translation of strings the site shares with the app (`appMatch`); the app's `fr.lproj/Localizable.strings` in the sotto repo (`sotto-ios/Targets/Sotto/Resources/`) is the reference for any other screen or field name. Never contradict the app's wording; add a row here for a word the pages repeat, so every page and guide says it the same way.

Fill "Term in language" with the one word or phrase every page will use, as a reader in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| People notes app (the product category) | carnet privé pour vos proches | Category noun, from the store subtitle (fr-FR “Carnet privé: proches, cadeaux”) and app name “Ceux que vous aimez”. Say “app” (the app writes “l’app”, never “logiciel”). Search term “CRM personnel” (SWEET in aso-keywords.md): use it once, in the sentence that says Sotto is a personal CRM for your people — see the Personal CRM row. Never “carnet d’adresses”, “répertoire” or “contacts” as the category (readers expect a contacts tool; Gmail/Chrome results); “notes sur les gens” has no search demand |
| Person page (a page for every person) | une page pour chaque personne | The app says “Personne / Personnes” (tab.people, editPerson.newTitle “Nouvelle personne”); no screen is called “page”. Use “page” in the marketing sense only. Not “fiche” (administrative, CRM-form feel), not “profil” (social network). A person = “personne”, never “contact” |
| Note (a dated note about a person) | note / notes | from app strings: personDetail.noteSection “Note”, personDetail.sectionNotes “Notes”, addNote.title “Ajouter une note”. Feminine: une note. Not “mémo”, “remarque” |
| Field (size and measurement fields) | champ / champs | from app strings: editPerson.addField “Ajouter un champ”, editPerson.fieldsSection “Champs”, customField.title “Champ personnalisé”. Size/measurement fields = “champs de tailles et mensurations” (existing site wording); the app group is “Tailles” (personDetail.groupSizes). Not “rubrique”, “zone” |
| Ring size / shoe size | taille de bague / pointure | from app strings: settings.unitRingSize (“Taille bague” is the shortened label — write “taille de bague” in running text), settings.unitShoeSize / field.shoeSize “Pointure”. Ring-size chart = “tableau des tailles de bague”. Systems stay US / EU / UK / JP (unit.ring*). Fingers: “annulaire”, “auriculaire”, “majeur”, “index”, “pouce” (field.finger.*); left/right = “main gauche / main droite” in prose (the app abbreviates “G.” / “D.” only in labels). Not “tour de doigt” (jeweller jargon) |
| Gift idea / gift log | idée cadeau / carnet de cadeaux | Gift idea: from app strings field.giftIdeas “Idées cadeaux” (singular “idée cadeau”). Gift log (what you gave, when, for which occasion) = “carnet de cadeaux”, verb “tenir un carnet de cadeaux” (matches the SWEET store term “carnet cadeaux”). Keep it apart from “liste de souhaits” (field.wishlistUrl “Souhaits”) which is what someone wants. Not “liste de cadeaux” (wedding/birth list), “registre”, “journal de cadeaux” |
| Conversation question (the question catalog) | question de conversation / catalogue de questions | Catalog noun (existing site wording): “catalogue de questions”; one item: “question de conversation” (or “question pour lancer la conversation”). App screen: promptCatalog.title “Choisis une question”, promptCatalog.searchPlaceholder “Chercher une question”, promptCatalog.countSuffix “%d questions”. The app’s title uses tu while the site uses vous: when you must name the screen, quote it exactly in guillemets « Choisis une question »; otherwise describe it (“choisissez une question dans le catalogue”). Not “prompt”, “brise-glace” as the term |
| Guides (the article pages) | Guides | Nav/section label (existing site: nav.guides “Guides”, back link “Tous les guides”, related “Guides associés”). A single article is “un guide”. Not “tutoriels”, “articles” |
| FAQ / frequently asked questions | FAQ | Nav label and page title “FAQ”; spell out “questions fréquentes” only inside sentences. Not “Foire aux questions” |
| Privacy Policy | Politique de confidentialité | from app strings: settings.privacyPolicy. Lowercase “confidentialité” (the existing site title “Politique de Confidentialité” is wrong by the app’s wording). The short nav/footer label “Confidentialité” is allowed only where en shows a short label (nav.privacy is “Privacy Policy”, so prefer the full term) |
| Terms of Use | Conditions d’utilisation | from app strings: settings.termsOfUse. Lowercase “utilisation”. Apostrophe: typographic ’ in new text; copy an appMatch value as given |
| One-time purchase, no subscription | achat unique, sans abonnement | from app strings: paywall.oneTimePurchase “Achat unique · À vie”, paywall.subtitle “Un seul achat. Aucun abonnement.”. Verb: “acheter une seule fois”. Never “paiement unique” as the term. Paid state: “à vie” (settings.proBadge “À VIE”, paywall.unlockButton “Débloquer à vie”); verb “débloquer”. Upgrade tier is “Pro” |
| Back up / restore (to your own cloud) | sauvegarde / sauvegarder, restaurer | from app strings: settings.backup / backup.title “Sauvegarde”, backup.backupTo “Sauvegarder sur %@”, backup.restoreFrom “Restaurer depuis %@”, backup.restoreAction “Restaurer”. Own cloud = “votre propre cloud” (iCloud, Google Drive, Dropbox — names unchanged; backup.description says “service cloud”). Not “backup” as a noun, not “copie de sécurité” |
| On your phone (data stays on the device) | sur votre téléphone | Warm site wording for “everything stays local”, iPhone and Android alike. In legal text and where the app says it, use “sur votre appareil” / “en local” (appLock.footerTag “PRIVÉ · LOCAL UNIQUEMENT”). Never “dans le téléphone”; for iPhone-only sentences name “iPhone”. Not “portable”, “mobile” as the noun |
| Personal CRM (as the FAQ and hero describe Sotto) | CRM personnel | Verbatim SWEET store term (aso-keywords.md, fr-FR keywords field). Use in the one sentence that says Sotto is a personal CRM for the people you love; always uppercase “CRM”, masculine (un CRM personnel), no acronym explanation. Do not repeat it in every paragraph |
| Reminder (birthday / anniversary notification) | rappel / rappels | from app strings: notification.title “Rappels”, notification.sevenDaysBefore (7 days before). Date field = “champ de date” (notification.noDateFields). Not “alerte”; “notification” only for the system permission (notification.systemDisabledMessage) |
| Birthday / anniversary | anniversaire / anniversaire de couple | Birthday = “anniversaire” (field.birthday), date of birth = “date de naissance” when the sense is the date. Couple anniversary = “anniversaire de couple” (field.anniversary “Anniv. de couple”, shortened in the app only); never bare “anniversaire” when the couple’s date is meant, to avoid the clash |
| Height vs. size | stature (champ) / taille | The app labels height “Stature” (field.height), waist “Taille” (field.waist), clothing size “taille”. Use “stature” for the height field and when a sentence means height; “taille” for clothing, ring and general size; “tour de taille” for waist in prose. Never write “sa taille” if height could be read as clothing size |
| App Lock | Verrouillage de l’app | from app strings: settings.appLock. Face ID / Touch ID / iCloud stay untranslated; passcode = “code” (settings.appLockDescription “Face ID ou le code”) |
| Color themes | thèmes | from app strings: paywall.themes “Les 7 thèmes”, themePicker.title. Counts follow en (8 in en; the app’s 7 is the app’s). Not “skins”, “thèmes de couleurs” only as in the existing “8 thèmes de couleurs” phrase |
| No account / no sign-up | sans compte | from app strings: paywall.noAccount “Aucun compte”. “Sans inscription” is fine when sign-up/login is meant. Not “sans profil” |
| Free (free version / free limit) | version gratuite | from app strings: paywall.personLimitMessage “La version gratuite …”, paywall.limitReachedTitle “Limite gratuite atteinte”. “Gratuit pour commencer” |
| Settings (iOS screen name) | Réglages | from app strings: settings.title. Android readers: still “Réglages” on the site unless en says “Settings” for Android only, then “Paramètres” |
| Address form (register) | vous | Warm, one person, formal-friendly. “vous / votre / vos” throughout the segment; never tu (the existing site and store listing use vous). Gender-neutral wording where easy: “vos proches”, “les personnes qui comptent pour vous”, avoid écriture inclusive with points médians |
| People you care about (recurring phrase) | vos proches / les personnes qui comptent pour vous | Recurring “the people you care about / love”. Vary: “ceux que vous aimez” (the app name’s wording “Ceux que vous aimez”), “les personnes qui comptent”. “Proches” covers family and friends; do not use for partner-only sentences |
