# Site glossary — Deutsch (de)

Copied from `_template.md`. The de translator fills it before translating any packet, and the reviewer holds every de value to it.

The Sotto app has no glossary file. Its own wording reaches every packet as the app's exact translation of strings the site shares with the app (`appMatch`); the app's `de.lproj/Localizable.strings` in the sotto repo (`sotto-ios/Targets/Sotto/Resources/`) is the reference for any other screen or field name. Never contradict the app's wording; add a row here for a word the pages repeat, so every page and guide says it the same way.

Fill "Term in language" with the one word or phrase every page will use, as a reader in that market searches for it. Add a row for any other site-only word that repeats across pages.

| en | Term in language | Note |
|----|------------------|------|
| People notes app (the product category) | Notizen-App für Menschen | Short form „Menschen-Notizen“ (as in the store subtitle). Search terms: „Notizen zu Menschen“, „Kontakte Notizen“ — use once where the sentence is about the category, never stuff. Not „Kontakte-App“ / „Adressbuch“ (reader expects a contacts tool). Always „App“, never „Software“ |
| Person page (a page for every person) | eigene Seite für jede Person | The app shows people as „Person / Personen“ (tab.people, editPerson.newTitle); no screen is called „page“. Say „Seite“ only in the marketing sense; as a noun on its own „Personenseite“ is fine. Not „Profil“ (sounds like a social network) |
| Note (a dated note about a person) | Notiz / Notizen | from app strings: personDetail.noteSection, personDetail.sectionNotes, addNote.title („Notiz hinzufügen“). Feminine: die Notiz. Not „Anmerkung“, „Memo“ |
| Field (size and measurement fields) | Feld / Felder | from app strings: editPerson.addField („Feld hinzufügen“), editPerson.fieldsSection. Custom field = „eigenes Feld“ (customField.title „Eigenes Feld“). Size/measurement fields = „Größen- und Maßfelder“ or „Felder für Größen und Maße“; the app group is „Größen“ (personDetail.groupSizes) |
| Ring size / shoe size | Ringgröße / Schuhgröße | from app strings: settings.unitRingSize, settings.unitShoeSize (field.shoeSize). Ring size chart = „Ringgrößentabelle“. Ring size systems stay US / EU / UK / JP (unit.ring*). Height: the app label is „Größe“ (field.height), so in running text write „Körpergröße“ to keep it apart from clothing/ring sizes |
| Gift idea / gift log | Geschenkidee / Geschenkeliste | Gift idea: from app strings field.giftIdeas („Geschenkideen“). Gift log (a record of what you gave, when, for which occasion) = „Geschenkeliste“ (verb „führen“: „eine Geschenkeliste führen“); keep it apart from „Wunschliste“ (the app's wish-list field, field.wishlistUrl) which is what someone wants. Not „Geschenkprotokoll“ (too bureaucratic) |
| Conversation question (the question catalog) | Gesprächsfrage / Fragenkatalog | Button/screen wording from app strings: promptCatalog.title „Eine Frage aussuchen“, promptCatalog.searchPlaceholder „Frage suchen“ — write the button exactly so. Site noun for the catalog: „Fragenkatalog“, one item: „Gesprächsfrage“ (conversation starter = „Gesprächseinstieg“ only when meaning the idea). Not „Prompt“ |
| Guides (the article pages) | Ratgeber | Nav/section label and „Alle Ratgeber“ for back link; a single article is „Ratgeber“ too (der Ratgeber). Not „Anleitungen“ (reads as a manual), not „Guides“ |
| FAQ / frequently asked questions | FAQ / Häufige Fragen | Nav label and page title „FAQ“ (as in German app stores); spell out „Häufige Fragen“ only in sentences |
| Privacy Policy | Datenschutzrichtlinie | from app strings: settings.privacyPolicy. Not „Datenschutzerklärung“ (the app's term wins) |
| Terms of Use | Nutzungsbedingungen | from app strings: settings.termsOfUse |
| One-time purchase, no subscription | Einmalkauf, kein Abo | from app strings: paywall.oneTimePurchase „Einmalkauf · Lebenslang“, paywall.subtitle „Einmal kaufen. Kein Abo.“. Verb: „einmal kaufen“. Never „Abonnement“. The paid state is „Lifetime“ / „lebenslang“ (settings.proBadge „LIFETIME“, paywall.unlockButton „Lebenslang freischalten“); free tier: „kostenlos“, „kostenlos starten“ |
| Back up / restore (to your own cloud) | Backup / sichern, wiederherstellen | from app strings: backup.title „Backup“, backup.backupTo „Backup auf %@“, backup.restoreAction „Wiederherstellen“. Noun „das Backup“; verb „ein Backup erstellen“ or „sichern“. Own cloud = „dein eigener Cloud-Speicher“ (iCloud, Google Drive, Dropbox). Not „Datensicherung“, not „Sicherung“ as the main noun (the app only uses it in backup.legacyTitle) |
| On your phone (data stays on the device) | auf deinem Handy | Warm site wording for everything stays local (Android and iPhone alike; „Smartphone“ is acceptable once in a while). In legal text and where the app says it, use „auf deinem Gerät“ / „lokal“ (appLock.footerTag „PRIVAT · NUR LOKAL“). Never „im Telefon“; for the iPhone-only sentence name „iPhone“ |
| Personal CRM (as the FAQ describes Sotto) | persönliches CRM | Verbatim SWEET store-search term (aso-keywords.md). Use only in the sentence that says Sotto is like a personal CRM for people you love; keep „CRM“ uppercase, no explanation of the acronym needed |
| Reminder (birthday / anniversary notification) | Erinnerung / Erinnerungen | from app strings: notification.title „Erinnerungen“. Birthday = „Geburtstag“ (field.birthday), anniversary = „Jahrestag“ (field.anniversary); date field = „Datumsfeld“ (notification.noDateFields). Not „Benachrichtigung“ for the feature (only for the system permission) |
| App Lock | App-Sperre | from app strings: settings.appLock. Written with hyphen, capital S. Face ID / Touch ID / iCloud stay untranslated; „Code“ for passcode (settings.appLockDescription „Face ID oder Code“) |
| Color themes | Designs | from app strings: paywall.themes „Alle 7 Designs“, themePicker.title „Design wählen“. (en says 8 themes; the count is en's issue, not the glossary's.) Not „Themes“, „Farbthemen“ as the term |
| No account / no sign-up | kein Konto | from app strings: paywall.noAccount „Kein Konto“. „Ohne Anmeldung“ is fine as a variation when sign-up/login is meant. Not „Account“ |
| Free (free version / free limit) | kostenlose Version | from app strings: paywall.limitReachedTitle, paywall.personLimitMessage („Die kostenlose Version …“). Upgrade/Pro: „Pro“, „Lifetime“ |
| Address form (register) | du | Warm, one person. Lowercase du/dir/dein in running text (the app does the same). Imperative without „Bitte“ where the app does; never Sie. Gender-neutral language: avoid colon/star forms; prefer neutral wording (die Menschen, die dir wichtig sind) |
| People you care about (recurring phrase) | die Menschen, die dir wichtig sind | Recurring „the people you care about / love“. Vary with „die, die dir am Herzen liegen“; avoid „Liebste“ unless a romantic sense is meant. Single contact = „Person“ (the app never says „Kontakt“ for a person); “Kontakt” only for phone/email info (personDetail.groupContact) |
